# AI-Based Interview Portal

## 📌 Project Overview

AI-Based Interview Portal is a web-based application developed to help students and job seekers prepare for technical interviews.

The application provides interview questions, user authentication, profile management, dashboard, resume validation, and resume-based interview preparation features.

## 🎯 Objectives

- Help students prepare for technical interviews.
- Provide technology-wise interview questions.
- Allow users to create and manage their profiles.
- Provide resume validation functionality.
- Generate interview questions based on uploaded resumes.
- Make interview preparation easier and more organized.
- Provide a simple and user-friendly interface.

⚙️ Installation and Setup
Follow the steps below to run the project on your computer.
1. Clone the Repository
git clone https://github.com/snehkakkar995-cloud/AI_based_interview_portal.git
2. Navigate to the Project Folder
cd AI_based_interview_portal
3. Install Dependencies
npm install
4. Start the Development Server
npm run dev
5. Open the Application
After running the development server, open:
http://localhost:5173/
